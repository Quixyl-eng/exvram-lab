# Code of Conduct

ExVRAM Lab follows the [Contributor Covenant](https://www.contributor-covenant.org/) version 2.1, plus the research rules below.

## Research rules

- Report a number as measured only when this repository, or your pull request, contains the command and the record that produced it.
- Label planner output, file-size arithmetic, and untaken runs as `ESTIMATED`.
- Do not present the CPU synthetic microbenchmark as model tokens/second.
- Do not commit model weights, credentials, or another person's private host paths.
- Do not open a pull request that pretends to be from someone else.

## Expected behavior

Be considerate in issues, reviews, and discussions. Disagree about measurements and methods. Critique the record, not the person.

## Unacceptable behavior

Harassment, personal attacks, and publishing someone else's private information are not acceptable. So is knowingly submitting fabricated benchmark or quality numbers.

## Enforcement

Report conduct that should stay private through [GitHub private vulnerability reporting](https://github.com/ExVRAM/exvram-lab/security/advisories/new) and say that it is a conduct report. Maintainers will respond by warning, editing, or blocking further participation, depending on the incident.

Public technical disagreement belongs in an issue or pull request.
